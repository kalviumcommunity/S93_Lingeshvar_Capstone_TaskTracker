# TaskTracker - Capstone Project

## Project Idea & Description
TaskTracker is a full-stack MERN (MongoDB, Express, React, Node.js) web application designed to help individuals and small teams manage daily tasks, track project progress, and set priorities efficiently. Key features include user authentication, task organization by status/priority, deadline reminders, and an intuitive user dashboard.

## Day-by-Day Capstone Plan

- **Day 1:** Repository setup, README initial roadmap, branch workflow configuration, and PR initialization.
- **Day 2:** Mock UX design, wireframing user flows in Figma/Excalidraw, and architecture planning.
- **Day 3:** Backend environment setup, Express server initialization, MongoDB database connection, and User/Task schema design.
- **Day 4:** Authentication & Authorization implementation (JWT, bcrypt password hashing, login/signup API routes).
- **Day 5:** Development of primary CRUD API endpoints for creating, reading, updating, and deleting tasks.
- **Day 6:** Frontend React setup, folder structure organization, React Router implementation, and layout creation.
- **Day 7:** UI Component building: Auth pages, Navigation bar, Task cards, Modal forms, and Dashboard interface.
- **Day 8:** Integration of Frontend with Backend API endpoints and React state management for Task CRUD features.
- **Day 9:** Input validation, error notifications, responsive CSS styling, and visual UI polish.
- **Day 10:** End-to-end integration testing, bug fixing, deployment preparation, and final project documentation.
